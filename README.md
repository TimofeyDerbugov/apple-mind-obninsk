# Apple Mind — сайт магазина в Обнинске

Одностраничный сайт магазина техники и сервиса Apple Mind (Обнинск, проспект Ленина, 150).

**Сайт:** https://timofeyderbugov.github.io/apple-mind-obninsk/

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Главная: техника, ремонт, оплата и доставка, отзывы, контакты |
| `catalog.html` | Каталог с ценами, фильтрами, поиском и формой заказа |
| `privacy.html` | Политика конфиденциальности |
| `consent.html` | Согласие на обработку персональных данных |
| `cookies.html` | Политика cookie |
| `terms.html` | Пользовательское соглашение |
| `404.html` | Страница «Такой страницы нет» |
| `css/style.css` | Все стили |
| `js/main.js` | Формы, переключатель «Купить / Починить», маска телефона |
| `js/catalog-data.js` | Товары и цены каталога — меняйте цены здесь |
| `js/catalog.js` | Фильтры, поиск, сортировка и окно заказа |
| `js/cookies.js` | Баннер cookie, загрузка карты после согласия |
| `img/` | Фотографии магазина; `img/cat/` — фото устройств для каталога (Wikimedia Commons, авторы и лицензии — в `js/catalog-data.js` и внизу каталога) |

## Важно

- Формы работают для вида: данные никуда не отправляются и не сохраняются.
- Карта Яндекса загружается только после «Принять все» в баннере cookie.
- Фото взяты из карточки организации на Яндекс Картах. Чтобы добавить новое, допишите строку в `img/sources.txt` — workflow `Fetch photos` сам скачает и сожмёт его.
- В документах и подвале нужно вписать реквизиты владельца (подсвечены жёлтым): ФИО ИП, ИНН, ОГРНИП, почту.

## Как обновить сайт

Залить изменения в ветку `main` — GitHub Pages пересоберёт сайт за минуту-две.
